    3.2三种经典匹配器的数学本质

    1. Olson Correlative（粗捕获）：在 $(\Delta x,\Delta y,\Delta\theta)$ 网格上最大化平均似然：

    窗口候选的平均似然
    $$S(\boldsymbol{\xi}) = \frac{1}{N}\sum_{i=1}^N L\bigl(\Pi_{\text{grid}}(T(\boldsymbol{\xi})\,\mathbf{p}_i)\bigr)$$

    工程精髓是外层角度只旋转一次点云，内层 $(x,y)$ 循环直接加整数偏移查表。生产 matchers.cpp:L142-217 还有一轮连续 SDF 细搜，并用粗响应面的 Softmax 二阶矩输出协方差。

    2. ICP-P2P（经典点对点）：利用 MapField::descendToObstacle 找到最近障碍格 $\mathbf{q}_i$，残差为二维向量 $\mathbf{e}_i=T\mathbf{p}_i-\mathbf{q}_i$。雅可比含不可忽视的旋转力臂：

    点对点 ICP 2×3 雅可比与旋转力臂
    $$J_i = \frac{\partial (T\mathbf{p}_i - \mathbf{q}_i)}{\partial [x, y, \theta]^\top} = \begin{bmatrix} 1 & 0 & -(w_{y,i} - p_y) \\ 0 & 1 & +(w_{x,i} - p_x) \end{bmatrix}$$

    3. 2D NDT（体素正态分布变换）：把地图切分成体素（生产默认 $0.5\text{ m}$，本动画为显示椭圆采用 $0.9\text{ m}$），对至少含 3 个占据格的体素拟合均值 $\boldsymbol{\mu}$ 与协方差 $\Sigma$。激光点在 3×3 邻域内选择马氏距离最小的高斯，最大化 D2P 得分：

    2D NDT 目标函数与 Magnusson 近似 Hessian
    $$s_i = \exp\!\left(-\frac{1}{2}\mathbf{d}_i^\top \Sigma^{-1}\mathbf{d}_i\right), \quad \mathbf{d}_i = T\mathbf{p}_i - \boldsymbol{\mu}, \quad \mathbf{H}_{\text{NDT}} \approx \sum_i s_i\, J_i^\top \Sigma^{-1} J_i$$

    3.3从空白文件开始：最小 Correlative 窗口评分

    第一版只实现单轮粗搜：固定角度后旋转点云并转换到栅格系，随后穷举平移候选。它假定输入点已经过滤为有限值，并省略生产代码的连续 SDF 细轮、Softmax 协方差与 SPD 下界；网格定义、整数取整、评分归一化与最佳候选更新仍与共享浏览器数学核一致。非有限点防御见 3.6 的生产源码阶段 0。

    教学最小版：correlative_window_min.cpp（单轮粗搜）
    MatchResult correlativeWindowMinimal(
  const MapField & field, const Pose2 & prior,
  const Scan & scan, const MatchOptions & opt)
{
  MatchResult res;
  if (!field.valid() || scan.points.size() < 5) { return res; }
  const auto * grid = &field.grid();
  const int n = static_cast<int>(scan.points.size());
  const int nx = static_cast<int>(
    std::max(1.0, std::ceil(2.0 * opt.window_lin / opt.step_lin)) + 1);
  const int ny = nx;
  const int na = static_cast<int>(
    std::max(1.0, std::ceil(2.0 * opt.window_ang / opt.step_ang)) + 1);

  Pose2 best = prior;
  double best_score = -1.0;
  std::vector<Eigen::Vector2d> cells;
  cells.reserve(scan.points.size());

  for (int ai = 0; ai < na; ++ai) {
    const double th = wrap_angle(
      prior.theta + (ai - 0.5 * (na - 1)) * opt.step_ang);
    const double c = std::cos(th), s = std::sin(th);

    // 关键：每个角度只变换一次，nx*ny 个平移候选共享 cells。
    cells.clear();
    for (const auto & p : scan.points) {
      const double wx = prior.x + c * p.x() - s * p.y();
      const double wy = prior.y + s * p.x() + c * p.y();
      cells.push_back(grid->worldToGridF(wx, wy));
    }

    for (int yi = 0; yi < ny; ++yi) {
      const double dy = (yi - 0.5 * (ny - 1)) * opt.step_lin;
      const double offy = dy / grid->resolution;
      for (int xi = 0; xi < nx; ++xi) {
        const double dx = (xi - 0.5 * (nx - 1)) * opt.step_lin;
        const double offx = dx / grid->resolution;
        double score = 0.0;
        for (const auto & cell : cells) {
          score += field.likelihood(
            static_cast<int>(std::lround(cell.x() + offx)),
            static_cast<int>(std::lround(cell.y() + offy)));
        }
        score /= n;
        if (score > best_score) {
          best_score = score;
          best = {prior.x + dx, prior.y + dy, th};
        }
      }
    }
  }

  res.pose = best;
  eval_stats(field, best, scan, opt.inlier_gate, res.score, res.inlier_ratio);
  res.valid = best_score > 0.0;
  return res;
}
    旋转复用减少的是什么，没有减少的是什么？
    $$\text{朴素点变换次数}=N n_\theta n_x n_y,\qquad \text{复用后}=N n_\theta$$ $$\text{似然查表次数仍为 }N n_\theta n_x n_y$$

    因此旋转复用把点变换量降低 $n_xn_y$ 倍，但不会减少候选数量，也不会减少似然查表次数。它消除的是每个平移候选都重复做三角函数、SE(2) 变换和世界坐标转栅格坐标的浪费。

    如何判断“掉进局部极小”？
    • 不要只看一步 RMSE 是否下降：离散最近点关联切换后，优化目标本身就可能改变。
    • 比较同一初值、同一扫描、同一地图下的最终真值误差；RMSE 小不等于位姿正确。
    • 窗口捕获器用“枚举更多候选”换取全局性；局部优化器用“少迭代”换取速度，二者职责不同。
    • Field-GN 在本例可能凭借连续场走出错误盆地，但若真位姿不在其可下降盆地内，它同样没有全局保证。

    3.7真实修复复盘：那些曾毁掉精度的隐蔽 Bug

    Phase 2 修复的三个关键缺陷
    • Correlative 细轮双倍偏移：细轮围绕粗最优枚举，但 offx/offy 必须仍以 prior 为基准计算候选差；直接累加粗最优偏移会再次叠加一次。
    • ICP-P2P 旋转列恒为零：不能把旋转力臂误当成与法向量正交并归零；J 的第三列决定航向能否被修正。
    • NDT 协方差 N 倍过自信：体素逆协方差已含 m⁻² 量纲，对有效点求和后必须除以 last_used，否则点数增加会虚假缩小方差。
    实现边界也要诚实

    本页最小 Correlative 只复现共享数学核的单轮粗搜；生产 C++ 的细轮与协方差以源码步进为准。共享 JavaScript 核目前提供 ndtBuild 用于椭圆可视化，因此本页不另造一份 NDT 牛顿步数值实现。
