    4.2公式推导：为何等于“无数据关联的点-线 ICP”？

    对于世界系点 $\mathbf{p}_{w,i} = T(\boldsymbol{\xi})\mathbf{p}_i$，点-线 ICP 衡量它到墙体切线的垂直法向距离。而距离场 $\text{SDF}(\mathbf{p}_{w,i})$ 正好就是到最近墙壁表面的垂直有向距离！它的梯度 $\nabla \text{SDF} = (g_x, g_y)^\top$ 恰好就是墙壁的单位法向量 $\mathbf{n}_i$！

    链式法则雅可比 + Huber IRLS 正规方程
    $$r_i(\boldsymbol{\xi}) = \text{SDF}\bigl(\mathbf{p}_{w,i}(\boldsymbol{\xi})\bigr), \qquad \mathbf{J}_i = \frac{\partial r_i}{\partial \boldsymbol{\xi}} = \begin{bmatrix} g_x & g_y \end{bmatrix} \begin{bmatrix} 1 & 0 & -(w_{y,i} - p_y) \\ 0 & 1 & +(w_{x,i} - p_x) \end{bmatrix}$$ $$w_i = \begin{cases} 0 & |r_i| > d_{\text{trim}} \\ 1 & |r_i| \le \delta \\ \delta / |r_i| & \text{otherwise} \end{cases}, \qquad \Bigl(\sum w_i \mathbf{J}_i^\top \mathbf{J}_i + \lambda I\Bigr)\Delta\boldsymbol{\xi} = -\sum w_i \mathbf{J}_i^\top r_i$$

    因为它是标量残差 $r_i$ 且随长墙方向梯度天然近 0，所以在光滑墙面上扫描点可以无阻力地顺墙滑动，永远不会像点对点 ICP 那样被“离散格点”锁死或扯偏。

    4.3核心源码与两级组合 ComposedMatcher

    src/matchers.cpp : L300-356 & L699-705
    // 1) 截断动态遮挡外点 + Huber 权重
const double r = field.sdf(g.x(), g.y(), &grad);
if (std::abs(r) > opt.trim_dist) { continue; }
const double w = std::abs(r) <= opt.huber_delta ? 1.0 : opt.huber_delta / std::max(std::abs(r), 1e-9);
const double jth = grad.x() * (-(wy - pose.y)) + grad.y() * (wx - pose.x);
const Eigen::Vector3d J(grad.x(), grad.y(), jth);
H += w * J * J.transpose();
b += w * J * r;

// 2) 两级流水线防护：若精修得分显著低于粗匹配，直接退回 coarse.pose 防跑飞
MatchResult fine = fine_->match(field, coarse.pose, scan, opt);
if (!fine.valid || fine.score + 0.05 < coarse.score) { return coarse; }
return fine;

    4.4工程技巧与细节打磨

    为什么“先更新最优记录再更新位姿”与“循环结束二次评估”缺一不可？

    在第 it 轮里计算出的 best_pose 和 ravg 是当前位姿 $p^{(k)}$ 的成绩；执行 p += s_clip * dp 后若直接收敛退出，最后一跳的新位姿还没有测过 ravg！所以必须记录 best_pose（防止阻尼过冲时发散）并且在循环结束后对终态 p 再做一次 eval_pose 校验，只采纳残差更低的解（matchers.cpp:L335-382）。
