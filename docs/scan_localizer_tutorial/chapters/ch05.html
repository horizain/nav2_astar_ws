    5.2从零写最小 cov_from_hessian

    正确顺序只有六步：对称化 → 特征分解 → 特征值夹紧 → 求逆 → 残差缩放 → 物理方差下限。最关键的是第 3 步必须发生在求逆之前：不可观测方向不是“删掉”，而是变成一个有界的大方差。

    教学最小版：保留特征值夹紧，省略可配置参数与详细防御
    Cov3 cov_from_hessian(
  const Eigen::Matrix3d & H, double res_var)
{
  const Eigen::Matrix3d Hsym = 0.5 * (H + H.transpose());
  Eigen::SelfAdjointEigenSolver<Eigen::Matrix3d> es(Hsym);
  if (es.info() != Eigen::Success) { return Cov3::Identity(); }

  constexpr double kMinEig = 1e-4;
  const Eigen::Vector3d eig =
    es.eigenvalues().cwiseMax(kMinEig);
  const Eigen::Matrix3d H_inv =
    es.eigenvectors() * eig.cwiseInverse().asDiagonal() *
    es.eigenvectors().transpose();

  const double scale = std::max(res_var, 1e-4) * 2.0;
  Cov3 cov = scale * H_inv;
  cov = 0.5 * (cov + cov.transpose()).eval();
  cov(0, 0) = std::max(cov(0, 0), 1e-4);
  cov(1, 1) = std::max(cov(1, 1), 1e-4);
  cov(2, 2) = std::max(cov(2, 2), 1.2e-5);
  return cov;
}
    “最后把对角线抬到下限”不能替代特征值夹紧

    若先对含零特征值的 $H$ 求逆，数值上可能直接得到无穷或 NaN；即使某个实现勉强返回有限矩阵，协方差的方向结构也已经被奇异求逆破坏。正确做法是把 $\lambda_j$ 夹到 $10^{-4}$ 后再求逆，最后才分别施加 $10^{-4}\text{ m}^2$ 的平移物理下限与 $1.2\times10^{-5}\text{ rad}^2$ 的转角物理下限。

    H 与 Hd 的分工，必须写进数据流
    • H = Σ wᵢJᵢᵀJᵢ：这一帧扫描实际带来的信息。不可观测方向应保持为零或接近零。
    • Hd = H + 10⁻⁶ · max(diag(H), 1)：为了 Hd.ldlt().solve(-b) 能稳定求解而添加的数值正则项。
    • Σ = cov_from_hessian(best_H, best_var)：滤波测量噪声必须来自未阻尼的 best_H，不能来自 Hd。

    真实 LM 阻尼很小，且小于 $10^{-4}$ 的方向还会被再次夹紧，因此某些帧的 Σ(H) 与 Σ(Hd) 差异可能不明显。这恰恰说明不能靠“某一帧看起来差不多”证明做法正确；数据流语义才是验收标准。

    5.4线性代数本质：特征值分解揭露不可观测子空间

    在每条平行于 $x$ 轴的走廊墙壁上，$\nabla\text{SDF} = (0, \pm 1)^\top$，即每束点的雅可比 $g_x \approx 0$。于是 Hessian 矩阵为：

    未阻尼 Hessian 求逆与特征值下界夹紧
    $$H = \sum_i w_i \mathbf{J}_i^\top \mathbf{J}_i \approx \begin{bmatrix} \sim 0 & 0 & 0 \\ 0 & \gg 1 & * \\ 0 & * & \gg 1 \end{bmatrix}, \qquad H = Q \Lambda Q^\top \implies \Sigma_{\text{match}} = s \cdot Q\,\mathrm{diag}\!\Bigl(\max(\lambda_j, 10^{-4})^{-1}\Bigr) Q^\top$$

    设 $s=\max(\text{res\_var},10^{-4})\times 2$。沿轴零特征值被夹紧后，方差上界为 $s/10^{-4}$；横向的大特征值则得到很小方差，再被物理下限托底。于是各向异性 EKF 在增益 $K=P_{\text{pred}}(P_{\text{pred}}+R)^{-1}$ 中自然表现为：横向几乎完全信任激光，沿轴把权重交给里程计预测。5.3 的面板会给出本页 JS 30m×5m 教学场景的即时数值；仓库 C++ curated E5 的 30m×3m 场景记录为 $12.48\text{ m}^2$，对应约 120,000× 各向异性，二者场景与参数不同，不应当手填混用。

    5.6真实踩坑复盘：为什么门控曾误杀退化走廊？

    Phase 3 修复：max_eig vs min_eig（localizer_core.cpp:L617）

    早期的协方差门控试图检验“最大特征值 < max_cov_eig”，结果恰恰把沿走廊合理膨胀出 $12.48\text{ m}^2$ 的健康退化帧全杀掉了！门控真正该卡的是min_eig < cfg_.max_cov_eig（只要至少在一个方向上定位紧实，帧就绝不是坏帧，退化方向交给各向异性 EKF 自动信任预测）。
