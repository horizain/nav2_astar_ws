    6.2分支定界（Branch-and-Bound）的可采纳上界证明

    想在全球地图 $W \times H \times N_\theta$ 个格子上搜完一个都不漏，总候选量往往上千万。Cartographer 与 scan_localizer 用 swmax_[level] 在常数时间内算出“一个 $2^{\ell}\times 2^{\ell}$ 大块里的最高可能得分”：

    可采纳上界不等式（永不漏真解）
    $$B(\text{block } [b_x, b_x+2^\ell) \times [b_y, b_y+2^\ell), \theta) = \frac{1}{N}\sum_{i=1}^N \underbrace{\max_{(\delta x,\delta y)\in[0,2^\ell)^2} L(c_{x,i}+\delta x,\; c_{y,i}+\delta y)}_{\text{swmax\_}[\ell][c_{x,i}+b_x,\, c_{y,i}+b_y]} \;\ge\; \max_{\boldsymbol{\xi}\in\text{block}} S(\boldsymbol{\xi})$$

    优先队列每次弹出当前上界 bound 最高的块。一旦已经收满 top-K 个经过 kNmsLinM=0.5m 非极大值抑制的多峰候选，队列中凡是 bound <= worst_kept 的所有剩余大块直接整枝剪掉！

    6.3对比对照组：粒子滤波（AMCL-lite）的数值稳定性改造

    为了在仓库做公平对照组（E8/E9），我们按 Thrun《Probabilistic Robotics》完整实现了 ParticleFilter，并修复了初学者最容易写炸的三处数学细节：

    • 倒车反向分解（particle_filter.cpp:L130-136）：当机器人倒车时 $\mathrm{atan2}(dy, dx) \approx \pm\pi$，直接代入正交采样公式会让 $\alpha_1\,\text{rot}_1^2$ 放大航向噪声几十倍；因此 $|\text{rot}_1| > \pi/2$ 时必须翻转 $+\pi$ 并把平移符号取反。
    • log-sum-exp 防下溢：200 束光连乘似然很容易跌破 $10^{-308}$ 变成 IEEE 754 `0.0`，全转对数域减去 max_lw 后再 exp 并加上效光束缩放因子 beam_scale = min(1.0, 30/N) 防止单帧粒子塌缩。
    • 圆均值角估计：计算均值角度绝不能做线性加权平均（$\pm 179^\circ$ 平均变 $0^\circ$），必须用 $\mathrm{atan2}(\sum w_i\sin\theta_i, \sum w_i\cos\theta_i)$。

    6.5工程踩坑复盘：B&B 曾为何在冷启动卡死？

    Phase 2 修复：100% 激光越界剔除 + `worst_kept` 剪枝错乱（matchers.cpp:L804）

    早期代码规定“只要有一束激光在边缘处越界就丢弃整个候选方块”，导致机器人在大厅边缘时合法方块全被扔掉（pq 变空）。正确逻辑是：只对整块完全越界的那几束光线记 0 分，机器人搜索框严格限定在自由空间外接矩形 [free_xmin, free_xmax] 内。另一处 Bug 是多峰去重更新前未重算第 $K$ 优阈值，导致真解过早被误剪。
