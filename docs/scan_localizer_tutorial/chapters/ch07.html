    7.2先分流，再推公式：正常跟踪路径

    不要把五态都塞进同一套 EKF 公式。on_scan() 首先按入口状态分流：TRACKING 与 DEGRADED 继续走本章的预测—匹配—门控—更新路径；UNINIT、LOST、GLOBAL 在 L431-526 先尝试多假设验证或全局重定位，成功时重置滤波器并提前返回。恢复成功不是“正常测量更新”，因此实时面板不能假设它一定携带正常路径的 trace。

    入口状态本帧走向关键行为真实源码
    TRACKING正常 EKF 路径四门全过则 Joseph 更新；拒绝则纯预测并累计拒收。L528-757
    DEGRADED仍走正常 EKF 路径匹配恢复即可回到 TRACKING；持续拒绝可升级为 LOST。L528-729
    UNINIT / LOST / GLOBAL恢复旁路传播并验证假设，或调用 global_fn_；远距离跳变受安全门保护。L431-526

    状态向量增广至四维：$\mathbf{x}_k = [x_k,\; y_k,\; \theta_k,\; b_{g,k}]^\top$。compute_motion_delta() 先取两帧里程计之间的 SE(2) 增量；若有新 IMU 积分，则用扣除零偏后的角速度积分替换航向增量：

    运动增量、4×4 雅可比 F4 与过程噪声 Q4
    $$\Delta\theta = \operatorname{wrap}(\Delta\theta_{\text{raw}} - b_g\Delta t), \qquad \mathbf{p}^{-} = \begin{bmatrix} x + c\Delta x - s\Delta y \\ y + s\Delta x + c\Delta y \\ \operatorname{wrap}(\theta + \Delta\theta) \end{bmatrix}$$ $$F_4 = \begin{bmatrix} 1 & 0 & -(\Delta x\sin\theta + \Delta y\cos\theta) & 0 \\ 0 & 1 & \Delta x\cos\theta - \Delta y\sin\theta & 0 \\ 0 & 0 & 1 & -\Delta t \\ 0 & 0 & 0 & 1 \end{bmatrix}, \qquad Q_4 = \begin{bmatrix} G Q_{\text{body}} G^\top & 0 \\ 0 & q_b \end{bmatrix}$$ $$P_{k|k-1} = F_4 P_{k-1|k-1} F_4^\top + Q_4, \qquad P_{k|k-1} \leftarrow \operatorname{sym}(P_{k|k-1})$$

    这里 $P_{k-1|k-1}$ 表示上一帧滤波协方差，$G$ 只旋转平动噪声，$Q_{\text{body}}=\operatorname{diag}(q_{\text{trans}},q_{\text{trans}},q_{\text{rot}})$；使用 IMU 时 $F_4(2,3)=-\Delta t$，零偏随机游走写入 $Q_4(3,3)$。预测结束后才调用 matcher_->match(field, pred, scan, opt)。

    四门控、创新与各向异性 Joseph 更新
    $$H = \begin{bmatrix} I_3 & \mathbf{0}_{3\times1} \end{bmatrix}, \qquad R = \operatorname{sym}(P_{\text{match}}), \qquad S = \operatorname{sym}(\left(P_{k|k-1}\right)_{3\times3} + R) + 10^{-9}I_3$$ $$\boldsymbol{\nu} = \begin{bmatrix} p_{\text{match},x}-p^-_x \\ p_{\text{match},y}-p^-_y \\ \operatorname{wrap}(\theta_{\text{match}}-\theta^-) \end{bmatrix}, \qquad d^2 = \boldsymbol{\nu}^\top S^{-1}\boldsymbol{\nu}$$ $$\text{accept} = \underbrace{mr_{\text{finite}}}_{\text{总前提}} \land \underbrace{score \ge min\_score}_{\text{门 1}} \land \underbrace{inlier \ge min\_inlier}_{\text{门 2}} \land \underbrace{0 \le d^2 < mahal\_gate}_{\text{门 3}} \land \underbrace{0 < \lambda_{\min}(R) < max\_cov\_eig}_{\text{门 4}}$$ $$K_4 = P_{k|k-1}H^\top S^{-1}, \qquad \Delta\mathbf{x}=K_4\boldsymbol{\nu}, \qquad P_{k|k} = (I-K_4H)P_{k|k-1}(I-K_4H)^\top + K_4RK_4^\top$$
    严格按代码理解两个边界
    • mahal_gate 默认配置为 9.0；对当前配置它是一个固定阈值，判断为 mahal >= 0.0 && mahal < cfg_.mahal_gate。代码没有在运行时计算卡方分位数；不要把 9.0 当成分位函数的输入，也不要写成动态卡方阈值。等于 9.0 同样拒绝。
    • 第四门是匹配协方差 R 的特征值门：有限且 0 < λmin(R) < max_cov_eig。它不是检查预测协方差或创新协方差 S 的最大特征值。
    • mr_finite 要求匹配有效、位姿有限、score/inlier 有限且整个匹配协方差有限。它是四门的总前提，不是额外的“第五门”。

    源码在 L611-621 先分解 R 并算第四门，因为随后构造 $S$ 必须使用有效的 $R$；这不改变“Score / Inlier / Mahal / MinEig”的四门定义。创新 $\boldsymbol{\nu}$ 与 $S$ 是第三门内部的诊断量，K4 与状态修正只在四门全过后计算。

    7.3从零实现：最小 EKF 更新内核

    下面只保留正常跟踪的数学主干：运动增量 → F4/Q4/Ppred → matcher → 四门 → K4/innov → Joseph。为便于阅读，假设已经有里程计与初始位姿，并省略生产代码的输入过滤、传感器时间锚、first_fix_、可选修正限幅、异常窗口、状态降级和恢复旁路。它用于理解，不可直接替换生产实现。

    教学最小版：一次正常跟踪帧（C++，刻意省略生产防御）
    struct MinimalMotion {
  Pose2 delta{};
  bool imu_used = false;
  double dt_imu = 0.0;
};

// 对应 compute_motion_delta()：has_imu 表示本帧有尚未消费的 IMU 积分。
MinimalMotion compute_motion_delta_minimal(
  const Pose2 & odom_prev, const Pose2 & odom_now,
  bool has_imu, double imu_prev, double imu_now,
  double imu_dt, double gyro_bias)
{
  MinimalMotion m;
  m.delta = odom_prev.inverse() * odom_now;
  if (has_imu) {
    const double dth_raw = wrap_angle(imu_now - imu_prev);
    m.delta.theta = imu_dt > 0.0
      ? wrap_angle(dth_raw - gyro_bias * imu_dt) : dth_raw;
    m.imu_used = true;
    m.dt_imu = imu_dt;
  }
  return m;
}

bool ekf_tracking_minimal(
  const Pose2 & prior, double gyro_bias, const Cov4 & P,
  const MinimalMotion & motion, const MapField & field,
  const Scan & scan, const Matcher & matcher,
  const CoreConfig & cfg, Pose2 & pose_out,
  double & bias_out, Cov4 & P_out)
{
  const double th = prior.theta;
  const double c = std::cos(th), s = std::sin(th);
  const Pose2 pred(
    prior.x + c * motion.delta.x - s * motion.delta.y,
    prior.y + s * motion.delta.x + c * motion.delta.y,
    wrap_angle(th + motion.delta.theta));

  Eigen::Matrix4d F4 = Eigen::Matrix4d::Identity();
  F4(0, 2) = -(motion.delta.x * s + motion.delta.y * c);
  F4(1, 2) = motion.delta.x * c - motion.delta.y * s;
  if (motion.imu_used && motion.dt_imu > 0.0) {
    F4(2, 3) = -motion.dt_imu;
  }

  // 最小版只演示有里程计时的过程噪声；无 odom 分支见 L569-574。
  const double dtrans = std::hypot(motion.delta.x, motion.delta.y);
  const double q_trans = dtrans * cfg.odom_trans_var_per_m;
  double q_rot = dtrans * cfg.odom_rot_var_per_m +
    std::abs(motion.delta.theta) *
      (motion.imu_used ? cfg.imu_rot_var_per_rad
                       : cfg.odom_rot_var_per_rad);
  if (motion.imu_used && motion.dt_imu > 0.0) {
    q_rot += motion.dt_imu * cfg.imu_rot_var_per_rad;
  }
  Eigen::Matrix3d G = Eigen::Matrix3d::Identity();
  G(0, 0) = c; G(0, 1) = -s;
  G(1, 0) = s; G(1, 1) = c;
  Eigen::Matrix3d Q_body = Eigen::Matrix3d::Zero();
  Q_body(0, 0) = q_trans;
  Q_body(1, 1) = q_trans;
  Q_body(2, 2) = q_rot;
  Eigen::Matrix4d Q4 = Eigen::Matrix4d::Zero();
  Q4.topLeftCorner<3, 3>() = G * Q_body * G.transpose();
  if (motion.imu_used && motion.dt_imu > 0.0) {
    Q4(3, 3) = cfg.gyro_bias_rw_var_per_s * motion.dt_imu;
  }
  Cov4 Ppred = F4 * P * F4.transpose() + Q4;
  Ppred = 0.5 * (Ppred + Ppred.transpose());

  const MatchResult mr = matcher.match(field, pred, scan, cfg.match_opt);
  const bool mr_finite = mr.valid &&
    std::isfinite(mr.pose.x) && std::isfinite(mr.pose.y) &&
    std::isfinite(mr.pose.theta) && std::isfinite(mr.score) &&
    std::isfinite(mr.inlier_ratio) && mr.covariance.allFinite();
  const bool gate_score = mr_finite && mr.score >= cfg.min_score;
  const bool gate_inlier = mr_finite &&
    mr.inlier_ratio >= cfg.min_inlier_ratio;

  Cov3 R = Cov3::Identity();
  bool gate_cov = false;
  if (mr_finite) {
    R = 0.5 * (mr.covariance + mr.covariance.transpose());
    Eigen::SelfAdjointEigenSolver<Cov3> es(R);
    if (es.info() == Eigen::Success) {
      const double min_eig = es.eigenvalues().minCoeff();
      gate_cov = std::isfinite(min_eig) && min_eig > 0.0 &&
        min_eig < cfg.max_cov_eig;
    }
  }

  Eigen::Vector3d innov = Eigen::Vector3d::Zero();
  Cov3 S = Cov3::Identity();
  Eigen::LDLT<Cov3> ldlt;
  bool gate_mahal = false;
  if (mr_finite) {
    innov = Eigen::Vector3d(
      mr.pose.x - pred.x, mr.pose.y - pred.y,
      wrap_angle(mr.pose.theta - pred.theta));
    const Cov3 S_raw = Ppred.topLeftCorner<3, 3>() + R;
    S = 0.5 * (S_raw + S_raw.transpose());
    S += Cov3::Identity() * 1e-9;
    ldlt.compute(S);
    if (ldlt.info() == Eigen::Success && ldlt.isPositive()) {
      const Eigen::Vector3d v = ldlt.solve(innov);
      if (ldlt.info() == Eigen::Success && v.allFinite()) {
        const double mahal = innov.dot(v);
        gate_mahal = std::isfinite(mahal) &&
          mahal >= 0.0 && mahal < cfg.mahal_gate;
      }
    }
  }

  // 拒绝时只保留预测，不把坏测量融合进状态。
  pose_out = pred;
  bias_out = gyro_bias;
  P_out = Ppred;
  if (!(mr_finite && gate_score && gate_inlier &&
        gate_mahal && gate_cov)) {
    return false;
  }

  const Eigen::Matrix<double, 3, 4> S_inv_HP =
    ldlt.solve(Ppred.topRows<3>());
  if (ldlt.info() != Eigen::Success ||
      !S_inv_HP.allFinite()) { return false; }
  const Eigen::Matrix<double, 4, 3> K4 = S_inv_HP.transpose();
  const Eigen::Vector4d dx = K4 * innov;
  pose_out = Pose2(pred.x + dx(0), pred.y + dx(1),
                   wrap_angle(pred.theta + dx(2)));
  const double max_b = std::max(0.0, cfg.max_gyro_bias);
  bias_out = std::clamp(gyro_bias + dx(3), -max_b, max_b);

  Eigen::Matrix<double, 3, 4> H =
    Eigen::Matrix<double, 3, 4>::Zero();
  H.leftCols<3>() = Eigen::Matrix3d::Identity();
  const Eigen::Matrix4d I_KH = Eigen::Matrix4d::Identity() - K4 * H;
  P_out = I_KH * Ppred * I_KH.transpose() + K4 * R * K4.transpose();
  P_out = 0.5 * (P_out + P_out.transpose());
  return true;
}

    读懂这段代码的关键是：Ppred 在匹配之前已经确定；拒绝分支输出 pred / Ppred；只有 accept 之后才出现 K4 / dx 与 Joseph 第二项。生产代码另在 L663-673 做可选平移/转角修正限幅，在 L711-716 为“高分高内点、仅马氏拒绝”做温和协方差松弛。

    7.5三个“为什么”：拒绝、绑架与 Joseph

    为什么高分、高内点、仅马氏拒绝不能记为绑架？

    高分与高内点说明扫描和局部地图的几何形状仍然吻合；马氏拒绝只说明“这个修正相对当前先验太 surprising”。静止或原地转弯时过程噪声很小，先验可能过紧，几厘米的局部抖动就足以让 $d^2$ 越过门限。把它升级成绑架，会让对称走廊里的错误全局候选获得可乘之机。

    真实异常判定因此写成 !accept && (!mr_finite || score < anomaly_low_score || (!gate_inlier && !gate_score))。在高分、高内点、协方差有效、仅马氏失败时，该式为假；同时 L711-716 温和松弛先验，帮助后续帧恢复，而不是立即触发 GLOBAL。

    为什么用 Joseph 形式，而不是看起来更短的 (I-KH)P？

    在精确线性 Kalman 增益下，两种写法代数等价；工程差异来自浮点误差、各向异性与近似。(I-KH)P(I-KH)ᵀ 与 KRKᵀ 都以非负二次型形式出现，当 Ppred、R 为半正定时更容易保住对称性与半正定性，降低长走廊中负特征值风险。代码最后还做一次对称化。Joseph 不是万能保险：它不能替代输入门控、R 的最小特征值检查与有限性检查。

    为什么拒绝时要“纯预测”？

    门控拒绝意味着本帧测量没有被信任，此时若仍执行 K4 × innov，就等于把同一个坏修正塞回状态，逻辑自相矛盾。因此 L707-708 只提交 last_pose_ = pred 与 P4_ = P4_pred，不写测量更新。静止解锁时的 1.5 倍协方差松弛是主动增大不确定性，不是融合测量；状态仍保持预测值，out.accepted 仍为 false。

    7.7真实故障深度复盘：Intel Lab 两次 20 米神秘跳变是如何修掉的？

    提交 98fcd28 全程复盘：从 42 次误触发 GLOBAL 降至 0 次
    1. 病因 1（静止马氏锁死）：机器人在走廊原地停留或微转时，里程计位移 $\Delta s \approx 0$，导致预测方差膨胀量 $q_{\text{trans}}\approx 0$。当激光因局部噪声只偏几厘米但 $P_{\text{pred}}$ 很小时，$d^2 = \nu^\top S^{-1}\nu > 9.0$ 拒绝更新；越拒绝就越进纯预测，先验不动、次帧继续拒收，形成死锁！
      修复：在拒绝分支检查 gate_inlier && gate_score && gate_cov && !gate_mahal，适度按 1.5 倍松弛 $P_{3\times 3}$，再加对角微小增量并设置上限（L711-716），为后续帧和平解锁创造条件。
    2. 病因 2（对称走廊触发虚假绑架与跳变）：原 is_anomaly 把纯粹因为马氏门控拒绝的高分高内点帧误记为“遭到绑架”（触发了 42 次 GLOBAL），接着长相似走廊的外部/全局候选乘机把定位瞬移到 20m 外的对称通道。
      修复：① is_anomaly 严格剔除高分高内点帧（L650-652）；② 自动 GLOBAL 加上“远距离跳变保护”：只有已经有过有效定位（first_fix_）、非手动触发、跳变距离超过 global_jump_min_dist (1.0m)，且当前局部匹配健康（local_healthy）时，才应用“候选全局得分低于 local_mr.score + 0.15 则拒绝瞬移并加入多假设队列”的规则（等于该裕度时允许，L455-492）。

    这里只复述提交 98fcd28 已记录的两项 Intel Lab 结果：3,000 帧实测 GLOBAL 误触发 42→0，ATE RMSE 2.11m→0.56m；不额外引入无法核查的性能指标。对应回归为 HighScoreMahalRejectionDoesNotTriggerSpuriousGlobal 与 AutomaticGlobalJumpGuardProtectsHealthyTracking，可直接运行复核。
