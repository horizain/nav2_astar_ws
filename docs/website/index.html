2先建立的直觉 ①：里程计必然漂移

轮式里程计 = 把每一步 有误差 的位移连乘连加。

误差源典型大小后果
轮径磨损 / 打滑3% × 行驶距离走 5 m 漂 15 cm
轮距实际值 ≠ 标称值2% × 转过的角度原地转一圈偏 7°
地面打滑（地毯/瓷砖）随机、突发方向突然错

关键：误差是积分器 —— 不修正就只会越滚越大，永远不会自己变小。

SLAM 的全部工作 = 用外部观测（激光/相机）不断把漂移拉回来。后面五讲就是五种"拉回来"的数学方法。

3先建立的直觉 ②：信念是分布，不是一个数

硬说"机器人在 (2.3, 1.1)" 是假装不糊涂。

正确的表达是概率分布 —— "最有可能是这里，但旁边一圈也说得通"。

位置信念的三种表达： 单点 (2.3, 1.1) ← 简单，但丢失了"多不确定" 高斯 N(均值, 协方差) ← 第 ③ 讲 EKF 的世界（单峰） 粒子云 {(x₁,w₁), (x₂,w₂), …} ← 第 ④ 讲 PF 的世界（可多峰）

SLAM 全文的中心问题只有一个：分布怎么随「我动了」「我看到了」更新？

「我动了」→ 分布变宽变糊（不确定性增大）；「我看到了」→ 分布收窄变尖（不确定性减小）。整门课就是这八个字。

4先建立的直觉 ③：地图是概率场，不是照片

"墙"不是画上去的，是投票投出来的。

每个格子存一个占据概率：激光打到 → 投"占据"票；激光穿过 → 投"自由"票。

p > 0.65 → 占据（画成黑） ← 阈值可调 0.35 ≤ p ≤ 0.65 → 未知（灰） p < 0.35 → 自由（白）

投票制的好处：噪声票会被后续观测对冲。

一只路过的猫投了一次"占据"票，随后 100 束激光穿过那个格子 → 票被对冲，幽灵消失。 这就是动态物体不留永久鬼影的数学根基（第 ① 讲重点）。

5学习循环：怎么才算"学会了"

只看课程是学不会的。每讲请走完这个循环：

🧠 看懂直觉页 → ✍️ 手算页拿纸笔重算（数字都给了，自己列一遍表）→ 🖱️ 交互页改参数观察 → ✅ 测验页做对 → 🔧 工程页记住三个坑

检验标准：合上课程材料，能白板复述该算法的"输入 → 一步核心更新 → 输出"，并说出它什么时候会失败。做到才算过。
