学习地图

SLAM（同步定位与建图）要同时回答两个互为前提的问题：我在哪（定位）和 世界长什么样（建图）。没有地图怎么定位？定位不了怎么画地图？ 二十年的答案收拢成一个框架（图优化）+ 五个零件。下面六个交互模块，每个对应一个零件：

2 · 贝叶斯滤波噪声世界里怎么合并证据？逐步"测门/右移"，看信念条移动doc 21 §2

先建立三个直觉

① 里程计必然漂移：轮径磨损 3% → 走 5m 漂 15cm；航向差 2% → 每转一圈偏 7°。 误差是积分器，随时间累积——所以必须用外部观测（激光/相机）不断拉回。

② 信念是分布不是一个数：硬说"机器人在 (2.3, 1.1)"是假装不糊涂。 正确表达是概率分布，SLAM 全文都在回答"分布怎么随'我动了'和'我看到了'而更新"。

③ 地图是概率场不是照片："墙"只是占据概率 > 阈值的格子——噪声票会被 后续观测对冲（这是动态物体不留永久幽灵墙的数学根基）。

学习路径建议：先玩模块 → 读对应文档章节 → 拿纸笔重算 → 改参数看变化。 "看了就理解"来自这个循环，不来自任何单一材料。

1 · 占据栅格：log-odds 投票建图

已知位姿怎么画地图？—— 每束激光 = 一次投票：束端投"占据"，束中投"自由"

反演传感器模型：一束激光穿过一串格子——光束终点附近的格子被标记 占据（P=0.7），光束沿途格子被标记 自由（P=0.3），没扫到的格子不更新（保持 0.5）。

log-odds 更新： l_t = l_(t−1) + l_meas − l_0 其中 l = ln(p/(1−p))； p=0.7 → l=+0.847（占据票） p=0.3 → l=−0.847（自由票） 先验 l=0 减 l_0 的作用：让证据可对冲 —— 多次矛盾观测互相抵消，单次噪声伤不了累积证据

怎么读图

每格上方的数字是 log-odds l（下为概率 p）。颜色：红=占据(≥0.65)、 灰=未知(≈0.5)、蓝=自由(≤0.35)。 连续 3 束打同一面墙 → p 指数逼近 0.927 但永不到 1；一束噪声假回波会被之前的"自由"证据对冲 ——这就是动态物体不留永久幽灵墙的数学根基（doc 22 §3）。

动手：先连发 3 束（看 p 指数上升），再点"噪声"（看被对冲），再把 P(occ) 拉到 0.95 重发（看"焊死"效果——doc 22 警告的过度自信）。

2 · 贝叶斯滤波：噪声世界里合并证据

信念是分布不是一个数 —— 两步循环：预测（我动了）+ 观测更新（我看到了）

三格走廊，格子 1、3 有门。传感器：P(报门|有门)=0.8，P(报门|没门)=0.2。 运动命令右移一格：80% 成功、20% 打滑原地；格子 3 右墙挡住=原地。 实验序列：测到门 → 右移 → 再测到门（doc 21 §2 的手算序列）。

怎么读图

三格走廊（1、3 有门），下方信念条的高度 = 机器人对每个格子的置信度。 关键读数：第一次测门后格子 1 和 3 平分信念（多峰——世界对称，无法区分）； 右移后两峰摊开（0.378 / 0.533）；再测门后 74% 锁定格子 3。 一次运动 + 一次观测打破对称——这就是 AMCL 的原理（把分布换成粒子，见模块 4）。

动手：只按"观测"两次（不移动）——信念永远在 1/3 门之间平分； 然后按"自动演示"看完整序列。

3 · EKF-SLAM：高斯世界的"同时"估计

机器人 + 路标打包进一个高斯分布；观测让不确定性收缩、并产生"关联"

状态 x = [机器人位置, 路标位置]，先验 x̄=[1.0, 3.0]， Σ=[[σ_机器人², 0],[0, σ_路标²]]。机器人前进 u=1（预测），然后观测到 "路标在机器人前方 1.2m"（观测方程 z = 路标 − 机器人）。

预测： x̄ += u Σ̄ += 运动噪声 更新： K = Σ·Hᵀ/(H·Σ·Hᵀ+R) H=[−1,+1] （卡尔曼增益 = 观测的话听几成） x = x̄ + K·(z − H·x̄) Σ = (I − K·H)·Σ̄

怎么读图

横轴是位置（机器人起点 1.0 → 预测 2.0；路标固定 3.0）。蓝带 = 预测后机器人的不确定范围（±2σ），黄带 = 路标的不确定范围， 绿点 = 更新后的估计（协方差收缩）。

关键读数（默认参数，doc 21 §4.2 手算）：机器人方差 2.0 → 0.545（收缩）， 交叉协方差 0.364 ≠ 0 —— 机器人和路标从此"关联"（知道一个就能推另一个）。

动手：把 R（观测噪声）拉大 → 卡尔曼增益变小 → 收缩变弱（观测不可信时少听）； 把 σ²_运动 拉小 → 机器人更自信 → 更新听观测的更少。体会"增益 = 谁更准听谁的"。

4 · 粒子滤波：200 个"平行宇宙"从迷失到锁定

高斯假设扛不住多峰（走廊两头长得一样）—— 粒子群天生表示多峰

1D 世界 [0, 7m]，门在 1.0m 和 3.3m（非对称间距，故意打破对称）。 传感器报"到最近门的距离"（σ=0.05）；运动=前进 0.7m（σ=0.03）。 机器人真实位置 2.15m 出发（粒子不知道）。200 个粒子均匀撒满世界。

怎么读图

上条带 = 粒子分布直方图（每根柱 = 该位置有多少个粒子假设）；下条带 = 世界与两扇门； 红三角 = 机器人真实位置（点"显示真值"后可见，用于核对）。 关键读数：第一次测距后多峰存活（门两侧都像——诚实！）；移动 0.7m（门间距不对称） + 再测距 → 假设大批死亡，只剩真值附近；粒子标准差 = 定位置信度。

动手：点"自动"看三步收敛；然后"重置"后只按两次"测距"（不移动）—— 看多峰永远无法自我解决（这就是 doc 16"多峰评分陷阱"在定位里的对应物）。

5 · 扫描匹配：两帧激光怎么对齐

总分 = 匹配代价 + λ·‖偏移 − 里程计预测‖² —— 匹配分负责对齐，里程计先验负责"别乱跳"

5×5 地图（墙格代价=10），墙在 x=3 列。机器人激光点 S={(2,1),(2,2),(2,3)}。 拖动偏移滑块，看激光点被平移到不同候选位置、逐点代价与总分实时变化。

总分 = 匹配代价 + 2.0 × ‖(dx,dy) − 里程计预测(0.1, 0)‖² 匹配代价 = Σ 激光点投影处的地图代价（墙=10，自由=0）

怎么读图

绿点 = 平移后的激光点投影；红色格 = 撞上的墙（代价 10/格）。 关键读数：dx=0 与 dx=−1 的匹配代价打平（都是 0）——纯匹配分有歧义； 里程计罚项破平局选 dx=0。dx=+1 时三点全撞墙（代价 30）→ 一票否决 （doc 16"碰撞否决"的同款语义）。

动手：把 λ 拉到 0（完全不信里程计）→ −1 与 +0 的歧义重现； 拉到 10 → 机器人"完全相信里程计"，匹配被锁死在预测附近。 体会：λ 调的是信任分配——doc 22 的 variance_penalty 同族。

6 · 图优化：回环把漂移拉回来

位姿图 = 节点（位姿）+ 弹簧（约束，σ 小=硬弹簧）；回环是 SLAM 的灵魂

1D 机器人三位姿，x1 锚定 0。里程计边说 x3−x1 = 2.0（积分漂移了）； 回环边说"回到原地"= 1.8。拖动回环观测噪声 σ（= 这条边多可信）， 看全局解怎么在"信里程计"和"信回环"之间移动。

min J = (x2−x1−1)²/0.01 + (x3−x2−1)²/0.01 + (x3−x1−1.8)²/σ_loop² 解析解（x1=0）： 2x2 = x3 ； 5x3 − 4x2 = 5.8 （σ_loop=0.2 时）→ x3=1.933, x2=0.967

怎么读图

三个圆 = 位姿节点（大小 = 不确定性 ∝ σ）；连线 = 弹簧（粗细 = 权重 1/σ²）； 灰虚线 = 回环前的漂移位置（x3=2.0）。关键读数（σ_loop=0.2）： x3 被拉回 1.933，x2 被顺带拉到 0.967——一个回环约束改善整条链。

动手：σ_loop 拉到 0.05（回环极准）→ x3 贴近 1.8、x2 也大幅回移； 拉到 0.6（回环不可信）→ x3 几乎回到里程计的 2.0。 这解释了为什么"回环观测的 σ 是全图质量的总开关"（doc 21 §7）。
