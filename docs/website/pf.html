第 ④ 讲 · 粒子滤波

这一讲回答：双峰、非高斯的世界怎么定位？

第②讲走廊例子的遗留问题：信念是双峰的（两扇门都可能），高斯表达不了。 第③讲 EKF 单峰破产。

粒子滤波的答案朴实到惊人：别算分布了，直接养 N 个"活样本"代表它。

这一讲跑通：加权 → 重采样 → 收敛的完整循环，最后看它怎么长成 Gmapping/AMCL 这两大工程支柱。

0核心思想：用 N 个假设代替一张概率表

概率分布（解析） 粒子云（采样） bel = {0.444, 0.111, ≈ 粒子1 @格1 权重 0.8 0.444} 粒子2 @格3 权重 0.8 粒子3 @格2 权重 0.2 …（共 N 个）

三个要点：

  • 粒子 = 一个完整的假设："如果我真在位置 x，世界应该是这样" —— 粒子自带位姿（Gmapping 里还自带一张地图！）
  • 权重 = 这个假设的可信度（来自观测的似然）
  • 粒子云的形状 = 信念分布的形状：多峰？散开就是两个团。非高斯？随便什么形状都行
    • 和直方图滤波比：格子法在所有格子上"全面开花"，粒子法只把计算花在可能的地方 —— 高维时省得惊人。

    1算法循环：四步，永远循环

    ① 预测 每个粒子按运动模型动一步（各自带噪声） ② 加权 用观测给每个粒子打分 w_i = P(z | 粒子i的位置) ③ 重采样 按权重抽签：高分粒子多生，低分粒子绝育（可选，按需触发） ④ 估计 加权平均 = 当前位置估计 → 回到 ①
    对应贝叶斯滤波粒子版实现
    预测（搬运）每个粒子独立采样运动（蒙特卡洛积分）
    更新（打折）乘似然作权重
    归一化权重除以总和
    重采样不是每帧必须：权重越悬殊越该抽。判断指标 Neff —— 后面专页讲。

    2权重怎么算：高斯核打分

    观测 z（如"距最近门 0.45 m"），粒子预测值 ẑᵢ（"按我的位置算应该是 0.4 m"）：

    $$ w_i = \exp\!\Big(-\frac{(z - \hat z_i)^2}{2\sigma^2}\Big) \qquad\text{（}\sigma = \text{传感器噪声标准差}\text{）} $$
    $$ \hat z_i = z \;\text{差}\; 0 \rightarrow w = 1\;\text{（完美吻合）} \qquad \text{差}\;2\sigma \rightarrow w = 0.14\;\text{（边缘）} \qquad \text{差}\;5\sigma \rightarrow w \approx 0\;\text{（死刑）} $$

    本质：把"预测 − 实测"的距离换算成概率。σ 是唯一的旋钮 —— σ 就是传感器的诚实度：激光测距 σ≈0.02~0.05 m，所以粒子滤波里错 10 cm 的粒子直接判死。

    工程坑：σ 调太小 → 所有粒子权重同时≈0（全灭）；调太大 → 好坏粒子权重一样（失去分辨力）。要和真实噪声匹配。

    3重采样：轮盘赌怎么杀粒子

    权重 [0.5, 0.3, 0.15, 0.05] 归一化后做一条轮盘： |——— 粒子1 50% ———|— 粒子2 30% —|— 3 15% —|4| ↑ 转动 N 次指针，落在谁的扇区就复制谁

    规则：概率 = 权重。期望上，权重 0.5 的粒子被复制 N×0.5 次；权重 0.05 的粒子大概率一次都轮不到 —— 直接消失。

  • 复制体保持原位姿（可能加微小抖动 = 粗化）
  • 重采样后所有权重重置为 1/N（"新的一代重新起跑"）
  • 副作用：低权重粒子里的"少数派正确答案"可能被一起杀掉 —— 多样性损失，本讲后段专治

    ▶交互实验：200 粒子从迷失到锁定

    逐步点"测距→移动→测距"，看粒子云形态
    👀 观察任务
    • 初始：粒子均匀撒满世界 —— "完全迷失"的样子
    • 第一次测距：大部分粒子死亡，存活簇贴在真值附近
    • 移动+测距：粒子云整体平移并继续收紧
    • 锁定后：粒子标准差不再变小 —— 这是"收敛"的信号，继续跑不会更准

    5粒子数 N 怎么选：一张 trade-off 表

    NCPU表达力典型用途
    几十极低只够单峰收敛后的跟踪（AMCL 后期）
    几百~几千低2~3 个峰、中等噪声室内 SLAM 常规（Gmapping 默认 30~50 粒子另算）
    上万中绑架恢复、大初始不确定AMCL 初始撒点、重定位
    十万+高高维/超多峰通常不值得 —— 该换方法了

    工程共识：前期多、后期少 —— AMCL 的 KLD 自适应采样就是干这个的（后页）。

    判断粒子够不够的土办法：把 N 减半再跑一遍，结果轨迹不变 → N 够了。

    6粒子退化与 Neff：什么时候该重采样

    $$ N_{\text{eff}} = \frac{1}{\sum_i w_i^2} $$

    权重均匀 [1/N × N] → N_eff = N（健康：别重采样，白抽）； 权重集中 [1, 0, 0, …] → N_eff = 1（退化：必须重采样）。

    退化是必然趋势：每轮观测都会拉开权重差距，几轮后权重全堆在少数粒子上。

  • N_eff < N/2 → 触发重采样（AMCL 默认策略）
  • 重采样过频 → 多样性损失（下一页）；过疏 → 拿一堆死粒子做平均 → 估计有偏
    • N_eff 就是"信念实际由几个粒子撑着"。它同时是输出质量的体检指标： 锁定后 N_eff 低是正常的（单峰），但探索期 N_eff 就很低 = 粒子太少的警报。

    7重采样的三种抽法 + 多样性急救

    方法做法特点
    轮盘赌独立抽 N 次简单；方差最大（可能重复抽中同一个）
    系统采样 ★一根指针 + N 个等距刻度，每刻度复制对应粒子方差小、O(N)、工程默认
    残差采样整数部分直接复制，小数部分轮盘介于两者之间

    急救多样性两招：

  • 粗化 roughening：重采样后给每个粒子加微小随机抖动（σ≈N^(−2/D)），把"挤成一团"重新撑开
  • 随机注入：每轮随机撒少量均匀粒子（如 1%），权重极低但"保底"—— 绑架恢复的种子。AMCL 的 random limit 参数

    • 8从粒子到 Gmapping：每个粒子背一张地图

    纯 PF：粒子 = 位姿假设 Gmapping：粒子 = 位姿假设 + 一张专属栅格地图 ← Rao-Blackwell 化 为什么能这样：给定"我确实走了这条轨迹"，地图的更新是第①讲的确定性计算 （log-odds 投票）—— 不需要再采样，直接算。

    这就是 FastSLAM 的分解智慧：位置用粒子硬扛（多峰）， 地图用解析更新（便宜）。

  • 每个粒子维护自己的轨迹 + 自己的地图 → 回环时，正确轨迹的地图自洽、权重涨；错误轨迹的地图对不上、权重跌 → 自然选择
  • 代价：内存 × N 张地图。所以 Gmapping 默认只有 30 个粒子（不是几千）

    • 9Gmapping 参数对照（第⑦讲会实操）

    参数默认含义 / 对应本讲概念
    particles30N 个假设（每粒子一张地图，别开大）
    srr / srt0.01平移/旋转耦合的里程计噪声 —— 预测步的 Q
    stt0.01纯旋转噪声
    sigma_hit0.147似然打分的高斯 σ —— 权重页的 σ
    lstep / astep10粗到细搜索步 —— 第⑤讲的评分搜索
    map_update_interval5 s/map 发布频率（不是内部更新频率）
    新手通病：把 particles 调到 300 想"更准" → 内存与 CPU 爆炸，精度几乎不变。 精度瓶颈通常在 sigma_hit 与里程计噪声模型，不在粒子数。

    10粒子滤波什么时候会失败

  • ❌ 绑架问题（kidnapped robot）：机器人被抱到完全陌生的位置 —— 所有粒子都错、权重全 0、没有假设幸存。对策：随机注入（前页）+ 权重和过低时全局重撒
  • ❌ 粒子饥饿：真值恰好在某粒子附近，但它在上一轮被绝育 —— 1000 个粒子也救不了。 对策：粗化 + 注入；根本解是增加粒子或降低重采样频率
  • ❌ 高维状态：状态 6 维（AMCL 只有 3 维）时，覆盖同样密度需要指数级粒子 —— 换 EKF/UKF 或图优化
  • ❌ 动态场景误锁：一走廊的人把所有粒子的观测都对成"人墙" —— 需要鲁棒似然（截断高斯）

    • 11AMCL：粒子滤波在定位岗位上的工程形态

    地图建好后，PF 换个岗位：已知地图上定位（蒙特卡洛定位 MCL）。粒子不再背地图，只背位姿 —— 轻多了。

    AMCL 的工程改进解决什么
    KLD 自适应采样信念散（迷失）时自动加粒子，收敛后自动减 —— CPU 花在刀刃上
    随机粒子注入 (random limit)绑架恢复的种子
    odom alpha 5 参数运动模型噪声（第②讲那个 20% 的精细化版）
    laser z_hit / z_rand观测模型："真命中" 与 "随机噪声" 的混合比例
    nav2 默认定位栈 = map_server + amcl。 AMCL 崩掉的三大常见原因（初始位姿没给、odom 噪声 alpha 乱设、地图分辨率不匹配）—— 第⑦讲排障表见。

    ✎测验

    重采样后，某个"少数派但正确"的粒子簇权重被杀光。这属于粒子滤波的什么失败模式？

    • A. 绑架问题
    • B. 粒子饥饿 / 多样性损失
    • C. 数值下溢
    • D. 过度自信
    看答案与解析
    ✅ 正确答案：B. 粒子饥饿 / 多样性损失
    重采样是自然选择，会牺牲少数派。真值若恰在少数派中，后续观测再也救不回来（没有假设了）。粗化+注入是对策。

    ✎测验

    Gmapping 默认只有 30 个粒子，为什么不敢开几百个？

    • A. 粒子太多数值不稳定
    • B. 每个粒子携带一张完整栅格地图，内存与更新开销 × N
    • C. 粒子多会互相干扰
    • D. ROS 消息大小限制
    看答案与解析
    ✅ 正确答案：B. 每个粒子携带一张完整栅格地图，内存与更新开销 × N
    Gmapping 粒子=位姿+地图（Rao-Blackwell 化的代价）。AMCL 粒子只装位姿，所以敢开几千。

    12一页总结：粒子滤波

    N 个带权假设 = 信念分布的采样表达 循环：预测（各自动）→ 加权（似然）→ 重采样（按权重抽签）→ 估计（加权平均） 体检：N_eff = 1/Σwᵢ² 触发重采样 + 质量报警 衍生：Gmapping（粒子+地图 → 建图）、AMCL（粒子+已知地图 → 定位）

    带走三句话：粒子云=信念的形状 · 重采样=自然选择（会饿死少数派） · N 不是精度旋钮
