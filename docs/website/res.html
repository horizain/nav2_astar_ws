0经典书与课程（进阶路线）

资源定位读法建议
《Probabilistic Robotics》(Thrun)本课②~④讲的原著看 Ch.2-7：贝叶斯滤波 → KF/EKF → MCL；公式与本课一一对应
《视觉SLAM十四讲》(高翔)视觉向进阶 + 数学底子第 3/4 讲补李代数，第 10 讲位姿图与第⑥讲同源
Cyrill Stachniss 的 YouTube 课程免费视频课（SLAM/传感器建模）适合当"有声版"复习；Grid Maps / EKF / GraphSLAM 系列全
《State Estimation for Robotics》(Tim Barfoot)状态估计大部头想吃透 gtsam/因子图再啃
路线：本课 → 概率机器人 Ch.2-7 → 十四讲（视觉兴趣）/ Barfoot（深度兴趣）。

2保持练习：三个自测项目

学完七讲后，用这三个项目验收：

项目 A · 白板复述：不看材料，画出"扫描匹配 → 建图 → 回环"管线图并标注每步输入输出与失败模式。

项目 B · 手算重考：重做第⑥讲正规方程（改 σ：里程计 0.2、回环 0.05，问 x₃ 落哪？）—— 答案自验：加权融合公式。

项目 C · 实车对照：跑通 doc 20 的 slam_toolbox 全链路，故意把时钟弄不同步，复现"重影"故障并用第⑦讲速查表修好。

B 的答案：里程计链精度 1/(0.2²+0.2²)=12.5 < 回环 1/0.05²=400 → x₃ 紧贴回环的 1.8（≈1.802）。 这就是"标定好回环就能救烂里程计"的定量版。
