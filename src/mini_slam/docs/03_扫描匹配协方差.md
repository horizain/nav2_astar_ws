# 03 扫描匹配协方差：让信息矩阵有物理依据

对应 slam_toolbox / libkarto 的匹配协方差机制：边的强弱不该靠"响应×拍脑袋
的 σ"，而应来自**匹配响应面本身的形状**。

## 动机

correlative 匹配在窗口内穷举出一批候选位姿及其得分。这批得分构成一张
"响应面"，它的形状就是不确定性的直接描述：
- **单峰尖锐**（结构辨识度高）→ 位姿置信高 → 边要硬
- **平摊/多峰**（长墙滑移、对称场景）→ 位姿含糊 → 边要软
- **各向异性**（长走廊：沿墙方向含糊、垂直方向精确）→ 协方差非对角

之前我们用 `response² × 常数σ` 当信息矩阵——它只有一个标量自由度，
无法表达"这个方向准、那个方向糊"。

## 设计

粗搜索本来就产出了全窗口候选（用于方差门控），顺手从同一批候选估计
3×3 协方差（单遍累加，零额外搜索成本）：

```
w_i = (score_i / score_best)²          # 峰值归一的权重，压低弱响应
mean = Σ w_i·o_i / Σ w_i               # o_i = 候选偏移（相对粗最优）
cov  = Σ w_i·o_i·o_iᵀ / Σ w_i − mean·meanᵀ
```

进图时对角夹紧：σ 夹到 [match_sigma_min(0.02), match_sigma_max(0.50)]——
- 下限：防止过度自信把图焊死
- 上限：防止退化场景把边变得毫无约束

### `info_x / info_y` 的坐标系约定

边的平移信息矩阵对角元 **`info_x / info_y` 是世界（map）坐标系轴向**的，
不是 `from` 节点局部轴。SPA 残差里先用 `R(θ_from)` 把平移误差从局部系
旋到世界系，再按世界 x/y 分别加权：

```
e_xy = R(θ_from) · (Δt_ab − z_xy)
Δt_ab = R(θ_from)ᵀ (t_to − t_from)
```

也就是说**不同方向可以有不同刚度**。早期实现用单个各向同性标量
`max(σx, σy)` 会把长走廊这类"沿墙糊、垂直准"的几何信息丢掉；现在是
各向异性的世界系对角信息，V2 序列化也把 `info_x/info_y` 分别存盘。

## 验证（test_covariance.cpp）

1. **辨识场景**（房间+柱阵）：实测 σx=0.226、σy=0.228（注意：粗网格
   0.10m 的量化使 σ 有 ~0.2 下限，绝对值不代表好坏）
2. **退化场景**（40m 单面长墙）：cov_xx=0.066 vs cov_yy=0.034——沿墙
   方向各向异性约 1.9×；且沿墙平移 0.4m 后匹配得分变化 <0.1（平坦性
   直接证据）
3. **建图集成**：非闭环边的 `(info_x, info_y)` 实测出现 14 种取值，且
   存在 `info_x != info_y` 的各向异性边（当前测试场景 1 条）——信息矩阵
   随匹配质量与方向自适应，不再是常数，也不再被压成单个标量

## 踩坑

- 阈值测试最初要求"辨识场景 σ<0.15"，被粗网格量化打了脸——
  **协方差的绝对值受搜索分辨率支配，有意义的只有场景间的对比与各向异性**。
- 长墙场景的端点大多朝墙，360 束里只有朝下半球有回波——退化场景的
  "歧义"要看得分差的分布，不是看有效点数。
