# mini_slam 手动建图和导航

在 WSL 图形会话启动：

```bash
cd ~/ros2_ws/src/nav2_astar_ws
./run_mini_slam_mapping.sh
```

脚本打开 Gazebo、RViz 和操作终端。机器人模型、雷达与地图在 RViz 中显示；地图来自 mini_slam。导航使用项目的 AStarPlanner 和 PurePursuitController；AMCL 不发布 map→odom，定位由 mini_slam 提供。

## 建图

在操作终端长按 W/S 前进或后退，A/D 原地转向，空格停止。R/F 调整线速度，T/G 调整角速度。停止按键约 0.3 秒后发送零速。手动遥控直接发到底盘话题，绕过 Nav2 碰撞过滤链，请自行避障；不要在手动建图时发送导航目标。

## 保存和载入

在操作终端按 3，输入地图名称并回车。默认保存到 ~/mini_slam_maps，也可输入完整路径。会从同一份位姿图快照保存 .mmpg 位姿图和 .yaml/.pgm 栅格图，同时输出 .png 和 .meta；同名文件或临时文件已存在时不会覆盖。保存过程中不要关闭会话。

在新会话按 4 并输入已有地图名或完整路径前缀，程序先停止手动速度输出、切入定位，再加载位姿图和栅格地图。三种文件都必须存在；加载失败时会尝试恢复原模式和上一张导航地图。

## 定位和导航

保存完成后按 2 切换定位和导航；程序加载对应栅格地图，停止键盘速度发布。需要时在 RViz 使用 2D Pose Estimate 设置初始位姿，然后使用 Nav2 Goal 选择目标和朝向。红线显示全局规划路径，机器人由项目的 Pure Pursuit 控制器跟踪。

按 1 时，终端先取消导航和路径跟踪，等待目标进入终态并由新鲜里程计确认稳定停止，再切回手动建图。若服务结果或停止状态无法确认，终端会锁定手动输出并提示重启会话。按 Q 或关闭操作终端会结束本次仿真会话；再次启动时先按 4 加载之前保存的地图。

RViz 通过 /mini/display_map 显示当前地图：建图时转发实时地图，定位时显示加载的栅格地图。

## 自动化仿真验收

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
cd ~/ros2_ws/src/nav2_astar_ws
source install/setup.bash
python3 src/mini_slam/scripts/automated_session_test.py --domain 191
```

脚本在独立 ROS 域和 Gazebo 分区中启动自己的进程，通过真实操作终端自动完成
建图、同源快照保存、防覆盖及两种模式下的损坏图回退、静止定位、
两次 A* 规划与控制器导航、位姿图重载、继续建图和再次保存。
日志与地图保留在脚本输出的 /tmp/mini_slam_accept_* 目录。仅用于仿真；
不要将该 ROS 域连接到真实机器人。
